### 模块2 · 扫描 ✅ 串行流水线完整

**已有代码** (modules/02_scanning/):
- `ScanConfig.h` — 三模式开关（enableLaser / initialGlobalMarkers / enableFinalBA）
- `ScanPipeline.h/cpp` — **完整扫描流水线**（新增3文件）
- `ScanWorkflow.h/cpp` — 旧版扫描工作流（CPU标记点链，保留兼容）
- `ScannerWindow.h/cpp/ui` — 扫描仪控制窗口

**ScanPipeline 完整链路**:
```
预处理: mask_separation(CUDA) → ccl
├─ 标记点链(CPU,11步): split→zernike→merge→undistort→ellipse→match
│                     →epipolar_intersect→edge_match→reconstruct
│  → 配准: optical_flow_fuse (首帧I/0 或 对齐GlobalMarkerSet, 后续帧间链式)
│  → 融合: marker_cloud_fuse_cpu (体素哈希去重)
│
└─ 激光链(CUDA,5步): steger→undistort_cuda→epipolar_interp→laser_match_scan→laser_reconstruct
   → 用标记点R/T变换到全局坐标系
   → 融合: laser_cloud_fuse_cpu (体素哈希去重)
```

**三种扫描模式** (UI toggle按钮):
- **标点扫描**（情况A）: 纯标记点，enableLaser=false
- **面片扫描**（情况B）: 标记点+激光，enableLaser=true
- **点云扫描**（情况C）: 导入全局标记点+标记点+激光，首帧对齐导入点

**显示**: 标志点→同心圆(loadMarkerPoints)，激光点云→点(loadPointCloud)，每30帧刷新

**缺失**: 并行调度(E核/P核/GPU三槽)、帧间流水线
