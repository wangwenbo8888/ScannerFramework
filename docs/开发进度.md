## 1. 项目概述

手持式双目多线激光3D扫描仪软件框架，5层架构 + 11产品模块。

**性能指标**: 180fps · 0.01mm精度 · 50-100ms延迟 · Windows/Jetson双平台

| 文件 | 说明 |
|------|------|
| `modules/06_device_control/MCUDriver.h/.cpp` | Win串口实现IMCU，协议N10/N11/N12-N15，接收线程解析温度/按键/急停 |
| `modules/06_device_control/HardwareMonitor.h/.cpp` | 周期监控线程→DeviceStateCache+EventBus |

**MCU串口协议**:
```
N10 H{freq} B{bg} T{trig} V{ver} L{laser};  启动扫描
N11 H0;                                      停止扫描
N12 T0;                                      软触发
N13 L{level};                                激光功率
N14 B{level};                                补光灯
N15 E1;                                      急停
接收: T25.3;(温度) K1;(按键) E1;(急停)
```

## 4. 当前数据流（完整链路）

```
HAL CameraControl
    ↓ pushFrame()
DataPlane FrameBuffer (RingBuffer, DropOldest)
    ↓ popFrame()
Workflow CaptureStage
    ↓ getLatestFrame()
Workflow PreprocessStage → MarkerStage → LaserStage (并行待实现)
    ↓
Workflow FuseStage
    ↓ pushPointCloud()
DataPlane PointCloudBuffer (双缓冲+版本快照)
    ↓ getSnapshot()
UI MainWindow 系统信息面板 (实时点云数量)

HardwareMonitor → DeviceStateCache → UI (温度/帧率/连接)
StateMachine → EventBus → StateChanged 事件
```

## 7. 关键设计决策

| 决策 | 理由 |
|------|------|
| Data层唯一所有者 | 上层经窄接口读写，不获数据指针；每对象仅一个★写者 |
| UI层全局只读 | 绝无C/U/D；渲染走直读快照(ADR7.8)，其余走Service查询 |
| Algorithm层零数据权限 | 纯函数叶子；调用方负责读Data→传参→算→写Data |
| HAL经Sink回填 | 依赖倒置：Data定义IFrameSink，HAL推数据不感知Data |
| skip-layer窄接口 | Workflow→DataPlane直读写需ADR编号+CMake白名单约束 |
| AppContext中央装配 | 创建并拥有全部对象，注入WorkflowContext，统一生命周期 |
