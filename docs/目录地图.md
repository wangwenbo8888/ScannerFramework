### 功能 / 原理 / 核心参数 速查

#### 光顺管线(自适应平滑)

| 模块 | 功能 | 原理 | 核心参数 |
|---|---|---|---|
| `adaptive_smoother` | **主入口**:编排预处理+迭代 | pImpl 模式,串联所有阶段 | `preset`(precision/balanced/aggressive) |
| `adaptive_laplacian` | Taubin 双通平滑(去高频保体积) | λ 正向平滑 + μ 反向补偿,每步预测式截断防超差 | `base_lambda=0.2`,`iterations=60`,`max_local_drift=0.01mm` |
| `spike_remover` | 移除扫描毛刺/凹陷 | PCA 偏离比 ratio=\|d_v\|/d_mean,绝对值判定,迭代≤5 轮 | `spike_ratio_threshold=10.0`,`spike_ring=2` |
| `curvature_field` | 曲率场 + 法向定向 | 1-ring PCA 法向 + BFS 全局定向;三尺度曲率 | `curvature_ring_primary=2`,`aux=3` |
| `blemish_corrector` | 修正凹槽瑕疵 | 沿法向推至邻居中位数 d_v | `blemish_correction_max_delta_factor=3.0`,`dv_deviation_threshold=0.03mm` |
| `classifier` | 顶点分类 + λ 调制 | 偏离比+二面角→分类→连续 λ 插值 | `lambda_mult_flat=1.0`,`sharp=0.3`,`feature=0.0` |
| `drift_budget` | 漂移预算约束 | 预测式截断 + 后置钳位 + 最终总钳位 | `max_local_drift=0.01mm` |
| `active_sharpening` | 主动锐化(默认关) | FEATURE 反法向位移 | `sharpen_strength=0.2`,`interval=1` |

#### 方向场计算

| 模块 | 功能 | 原理 | 核心参数 |
|---|---|---|---|
| `ComputeFeatureDirectionField` | 折脊边切向方向场 | 特征边切向平均 + 符号对齐 + 1-ring BFS 传播 | 默认源(无参数) |
| `ComputeBoundaryDirectionField` | 边界曲线切线方向场 | ring2 带边界曲线 + 9 点滑动窗口 PCA | 无参数 |
| `ComputeCurvatureDirectionField` | 全网格 PCA 方向场 | 2-ring 邻居 PCA,中间特征向量 e1 | 无参数 |
| #`ComputeCurvatureDirectionFieldDihedral` | **二面角区 PCA 方向场** | 仅 is_feature,BFS 6 跳沿折脊走,取 e2(最大特征值) | `pca_ring=6` |
| #`GroomDihedralDirectionField` | **硬剔除梳理** | k-ring 邻居符号对齐→初始均值→剔除超 45° 的→最终均值 | `k_ring=6`,`angle_threshold=45°`,`min_keep=3` |

#### 三角面重构(边翻转系列)

| 模块 | 功能 | 原理 | 核心参数 | 对齐度 | 翻转面 |
|---|---|---|---|---|---|
| `EdgeFlipAlign` | FAAR 内部的 1-ring 翻转 | 新旧对角线对齐度比较,新>旧+margin 则翻 | `margin=0.1`,`max_flip=30°`,`min_angle=10°` | 0.825 | ≈0 |
| `DirectionalFlip` | **1-ring 翻转独立包装** | 多轮 EdgeFlipAlign 直到收敛 | `max_rounds=10`,`margin=0.1` | **0.825** | **13(0.13%)** |
| `CrossRingDirectionalFlip` | **跨 ring CDT 边插入** | Sloan flip 序列开路;P0 法向只查翻转;P1 逐级搜索;P2 bestEdge 门槛 | `k_ring=2`(逐级到3),`min_angle=1-5°` | **0.885** | 1791(17.5%) |
| `AnisotropicRemesh`(FAAR) | **完整重网格化** | flip→split→collapse→relax 四阶段 | `split_factor=1.5`,`drift=0.02`,`max_rounds=10` | 0.884 | ≈0 |

#### 切向平滑(不改拓扑)

| 模块 | 功能 | 原理 | 核心参数 |
|---|---|---|---|
| `DihedralTangentialSmooth` | 沿方向场切向松弛 | 对称化各向异性余切加权质心;法向锁定;漂移截断 | `relax_step=0.5`,`drift=0.05mm`,`symmetric=true` |

#### 四边网格化(Instant Meshes 移植)

| 模块 | 功能 | 原理 | 核心参数 |
|---|---|---|---|
| `FieldRemesh` | 三角形→四边形 | 4-RoSy 方向场 + 4-PoSy 位置场 + 图提取→四边面 | RoSy 迭代,PoSy 格点间距 |
| `rosy_posy` | 4-RoSy/PoSy 原语 | 旋转对称兼容性 + 位置舍入 | 4-way(十字场) |

#### 辅助

| 模块 | 功能 | 原理 |
|---|---|---|
| `v1_internal` | V1 函数副本(邻接/边界/二面角/Cotangent/拉普拉斯) | 自包含,不依赖 V1 内部 API |
| `bfs_util` | N-ring 邻居收集 | 全局时间戳访问标记,避免每顶点 O(N) memset |
| `quality_metrics` | 网格质量度量 | 最小角 / 纵横比 / 面积均匀性 |
| `deviation_ratio` | 偏离比计算 | PCA 平面拟合 → ratio=\|d_v\|/d_mean |
| `feature_detector` | 特征检测器(可切换) | deviation(PCA)/ tensor(结构张量)/ multiscale(多尺度) |

## 六、翻转方法对比(实测 1.stl)

| 方法 | 文件 | 对齐度 | 翻转面 | 新边跨ring | 特点 |
