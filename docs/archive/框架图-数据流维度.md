# 框架图 · 数据流维度（各模块 CRUD 权限 + 对象边界）

> 基于框架5层架构，标注每个模块对数据对象的**增C 删D 改U 查R**权限。
> `★`=对象所有者(唯一写) `○`=只读消费 `—`=无权限

---

## 数据对象定义（11类）

| 代号 | 数据对象 | 物理位置 | 生命周期 |
|------|---------|---------|---------|
| F | Frame 帧数据 | DataPlane · RingBuffer | μs-ms（瞬态） |
| PC | PointCloud 点云 | DataPlane · 双缓冲 | 会话级 |
| MP | MarkerPoint 标记点 | DataPlane | 会话级 |
| CAL | Calibration 标定参数 | DataStore | 永久 |
| MESH | Mesh/Normal 网格法线 | DataStore | 永久 |
| SESS | Session 会话元数据 | DataStore | 永久（续扫） |
| DEV | DeviceState 设备状态 | DataStore · 原子变量 | 秒级刷新 |
| LIC | License 许可证 | DataStore | 永久 |
| PROJ | Project 工程文件 | DataStore · 磁盘 | 永久 |
| EDIT | EditHistory 操作历史 | DataStore | 会话级 |
| LOG | Log/Perf 日志性能 | 横切 · 磁盘 | 永久轮转 |

## 框架图（CRUD 权限标注）

```
┌─ HAL 层 (纯硬件操作) ──────────────────────────────────────────────┐
│                                                                     │
│  Camera1/2 Driver   F: ★C  (采集帧→Sink推入RingBuffer)             │
│  MCU Driver         DEV: R    (读温度/按键→发事件)                   │
│  LightDriver        —                                                │
│  HardwareMonitor    DEV: ★C  (周期采集状态→DeviceStateCache)         │
│                                                                     │
│  对象边界: HAL 只产出 F 和 DEV 原始值, 经 Sink/事件上行, 不持有业务数据│
└──────────────────────────────────────────────────────────────────────┘
                               │ F(写) DEV(事件)
┌─ Data 层 ────────────────────────────────────────────────────────────┐
│                                                                     │
│ ┌─ DataPlane (hot) ───────────────────────────────────────────────┐ │
│ │  RingBuffer        F: ★CRUD  (帧缓冲池, 超时丢帧)                │ │
│ │  PointCloudBuffer  PC: ★CRUD (前后台双缓冲, 版本快照)            │ │
│ │  MarkerStore       MP: ★CRUD                                     │ │
│ └──────────────────────────────────────────────────────────────────┘ │
│ ┌─ DataStore (cold) ──────────────────────────────────────────────┐ │
│ │  CalibStore        CAL: ★CRUD                                    │ │
│ │  MeshStore         MESH: ★CRUD                                   │ │
│ │  SessionStore      SESS: ★CRUD                                   │ │
│ │  DeviceStateCache  DEV: ★CRUD                                    │ │
│ │  LicenseStore      LIC: ★CRUD                                    │ │
│ │  ProjectStore      PROJ: ★CRUD                                   │ │
│ │  EditStore         EDIT: ★CRUD                                   │ │
│ └──────────────────────────────────────────────────────────────────┘ │
│                                                                     │
│  对象边界: Data 层是所有数据对象的唯一所有者; 上层经窄接口读写,      │
│           不直接持有数据指针                                        │
└──────────────────────────────────────────────────────────────────────┘

┌─ Algorithm 层 (纯计算叶子, 无数据权限) ──────────────────────────────┐
│                                                                     │
│  模块9 算子库    所有对象: —                                        │
│                                                                     │
│  对象边界: 数据以参数注入, 输出以Result返回, 不碰任何Store           │
│  调用方(Workflow)负责: 读Data→传参→算子计算→拿Result→写Data         │
└──────────────────────────────────────────────────────────────────────┘

┌─ Service 层 (状态/业务) ─────────────────────────────────────────────┐
│                                                                     │
│  模块1 温度补偿服务   CAL: R→U    (读当前参数→温度切换→更新生效参数) │
│                                                                     │
│  模块5 编辑服务       PC: U D      (裁剪/删除点)                     │
│                       MP: C U D    (增删改标记点)                    │
│                       EDIT: C R U D (操作历史栈, 全权限)             │
│                                                                     │
│  模块6 文件管理服务   PROJ: C R U D (工程导入导出, 全权限)           │
│                       PC: C        (导出PLY/STL)                    │
│                       CAL: C R     (标定参数导入导出)                │
│                       MESH: C      (导出STL)                        │
│                                                                     │
│  模块7 会话管理       SESS: C R U D (会话全生命周期, 全权限)         │
│                       PC: U        (断电续扫恢复点云)                │
│                                                                     │
│  模块8 设备监控       DEV: R U      (读硬件状态→更新缓存)            │
│  模块8 许可证管理     LIC: C R U    (激活/验证/权益)                 │
│                                                                     │
│  FaultHandler         DEV: R        (读故障状态→状态转换)            │
│  StateMachine         SESS: U      (状态切换写会话)                  │
│                                                                     │
│  对象边界: Service 可改业务数据, 但必须经 Data 层窄接口, 不缓存副本  │
└──────────────────────────────────────────────────────────────────────┘

┌─ Workflow 层 (编排) ────────────────────────────────────────────────┐
│                                                                     │
│  模块1 标定工作流     F: R          (采集标定图像)                   │
│                       CAL: C        (解算写入标定参数)               │
│                                                                     │
│  模块2 扫描工作流     F: R          (从RingBuffer读帧)              │
│                       CAL: R        (读标定参数)                    │
│                       PC: C U       (重建写入→融合更新)             │
│                       MP: C         (检测标记点写入)                 │
│                       DEV: R        (读温度→选标定参数)             │
│                                                                     │
│  模块4 后处理工作流   PC: R         (读原始点云)                    │
│                       MESH: C       (封装/法线生成)                  │
│                       PC: U         (重融合/光顺更新)                │
│                                                                     │
│  对象边界: Workflow 经 skip-layer 窄接口操作 DataPlane;             │
│           冷数据经 DataStore 接口; 读多写少, 写完即释放              │
└──────────────────────────────────────────────────────────────────────┘

┌─ UI 层 (接入端) ────────────────────────────────────────────────────┐
│                                                                     │
│  模块3 渲染显示      PC: R(直读)    (ADR7.8 只读快照, ≥30fps)       │
│                      MP: R(直读)                                       │
│                      MESH: R                                            │
│                                                                     │
│  模块3 标定导引      F: R          (显示标定板图像)                   │
│                      CAL: R        (显示当前标定状态)                │
│                                                                     │
│  模块5 编辑界面      PC: R         (显示选中状态)                    │
│                      MP: R         (显示标记点列表)                  │
│                      EDIT: R       (显示操作历史)                    │
│                                                                     │
│  模块6 文件界面      PROJ: R       (显示工程树)                      │
│                                                                     │
│  模块8 设备面板      DEV: R        (显示温度/帧率/连接)              │
│                      LIC: R        (显示授权状态)                    │
│                                                                     │
│  对象边界: UI 只读, 绝无 C/U/D; 渲染走直读快照, 其余走Service查询    │
└──────────────────────────────────────────────────────────────────────┘

┌─ 横切 ──────────────────────────────────────────────────────────────┐
│  模块10 可观测性     LOG: ★CRUD   (日志/性能/审计, 全权限)          │
│                      所有对象: R   (可订阅任意层指标埋点)           │
│  用户权限/鉴权       —            (不操作业务数据, 只管接入控制)      │
│  配置管理            —            (注入参数, 不持久化业务数据)        │

```
