# 框架图 P0/P1 改进

> 基于 `框架整体(2).md` §2，仅修改 P0/P1 项。

---

## P0：必须解决

### P0-1 模块8 拆分（消解上帝模块）

**问题**：设备管理跨4层+横切，CMake链全5层。

**拆法**：

| 拆出组件 | 归层 | 职责 |
|----------|------|------|
| DeviceMonitor | Service | 温度/帧率/按键/故障监控、状态缓存 |
| LicenseManager | Service（横切接入） | 加密狗/软授权/权益/试用 |
| HALDriver | HAL | 相机/MCU驱动、设备枚举 |
| DevicePanel | UI | 设备状态+激活界面 |

```
改前: 〔模块8〕跨 HAL·Service·UI·Data + 横切 (上帝模块)
改后: DeviceMonitor(Service) + LicenseManager(Service/横切) + HALDriver(HAL) + DevicePanel(UI)
```

### P0-2 急停通道显式画出

**问题**：急停走EventBus有排队延迟，安全不可接受。

**方案**：图中单独画**红色同步通道**，绕过队列。

```
急停路径:
  KeyHandler ──publishSync(EmergencyStop)──► LightDriver(停激光, <100ms)
                ╰──► 硬线并联(物理断电, <10ms)

  ※ EventBus常规事件走异步队列; 急停走同步直调, 不入队
  ※ 图中用红色粗线标注, 并注明 "<100ms 同步 / <10ms 硬线"
```

### P0-3 skip-layer 契约形式化

**问题**：Workflow→Data 直读直写若无约束，会蔓延成"谁都能直读Data"。

**方案**：每个skip-layer必须有ADR编号+窄接口。

| skip-layer路径 | 窄接口 | ADR |
|----------------|--------|-----|
| Workflow→DataPlane 读帧 | `RingBuffer::acquire(timeout)` | ADR7.x |
| Workflow→DataPlane 写点云 | `PointCloudBuffer::swapBack()` | ADR7.8 |
| UI(模块3)→DataPlane 只读 | `PointCloudSnapshot::getReadOnly()` | ADR7.8 |
| Service→DataStore 冷读写 | 各Store的标准CRUD | — |

**规则**：CMake依赖白名单CI强制——非白名单的skip-layer直接**构建失败**。

## P1：重要改进

### P1-1 控制边 vs 数据边区分

**问题**：Service编排Workflow + Workflow查询Service，图中分不清方向。

**方案**：图中用不同线型区分。

```
───►  实线 = 数据/调用边 (依赖)
─ ─►  虚线 = 查询边 (只读, 不持有引用)
═══►  红线 = 急停同步边
```

具体：
- Service ───► Workflow：控制边（execute/stop/pause 编排）
- Workflow ─ ─► Service：查询边（getState/getParams 只读）
- Workflow ───► DataPlane：热数据边（skip-layer 读写）

### P1-2 断电续扫事务边界

**问题**：会话元数据与产物持久化无原子性保证。

**方案**：

```
断电续扫持久化点:
  ① 每帧融合后: 点云双缓冲后台 → 异步刷盘(1s间隔)
  ② 每10帧: 会话元数据 checkpoint 落盘(帧号/时间戳/覆盖率)
  ③ 崩溃恢复: 读最后checkpoint → 校验点云文件完整性 → 续扫

  事务边界: metadata + pointcloud 同目录原子写(temp→rename)
  恢复粒度: 最丢10帧(~55ms@180fps)
```

### P1-3 故障隔离边界

**问题**：单设备掉线可能拖垮全局。

**方案**：图中HAL层标出隔离边界。

```
HAL 层 (每设备独立隔离):
  ┌─ Camera0 线程 (独立超时 1s) ──┐
  ├─ Camera1 线程 (独立超时 1s) ──┤  ← 任一崩溃: 上报故障, 不传染
  ├─ MCU 线程   (独立超时 2s) ────┤
  └─ 硬件监控线程 (独立) ──────────┘

  隔离机制:
  · 每设备独立线程 + 独立超时
  · 超时/异常 → 标记 LinkStatus::Error → 发 FaultOccurred 事件
  · 不阻塞其他设备线程
  · Service(FaultHandler) 决策降级/停止, 非 HAL 自行决策
```
