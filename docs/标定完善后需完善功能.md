# 标定完善后需完善功能

> 本文档记录标定流程跑通后，扫描流水线需要完善的各项功能。
> 当前状态：扫描链路代码完整，但部分功能依赖标定参数才能生效。

## 一、标定参数接入扫描流水线

### 1.1 标定结果 → ScanCalibration 自动传递

**现状**：标定完成后，参数存在 `MainWindow::m_lastCameraCalib`，扫描启动时手动拷贝到 `ScanPipeline::calib_`。

**待做**：
- [ ] 标定结果保存为 JSON 文件（`calibration.json`）
- [ ] AppContext 启动时自动加载 `calibration.json`
- [ ] ScanPipeline 直接从 AppContext 获取标定参数，无需手动传递
- [ ] 温度补偿表（`stereo_rectify_temp_table` 输出的 R1/R2/P1/P2/Q 分温度表）加载到内存

### 1.2 涉及的标定参数

| 参数 | 来源 | 用途 |
|------|------|------|
| cameraMatrixL/R, distCoeffsL/R | intrinsic_calib | undistort (CPU+CUDA) |
| R1, R2, P1, P2, Q | stereo_rectify_temp_table | 立体矫正 + 三角测量 |
| 激光平面映射温度表 | plane_map_temp_table | laser_match_scan 查表 |
| 曝光-温度补偿表 | extrinsic_compensate | 动态曝光调整 |
