## 数据流方向总览

```
           写入方向 ──►        查询方向 ─ ─►

HAL ──►F────►│ DataPlane │◄──CRUD── Workflow (热路径直读写)
     ──►DEV──►│           │◄──R───── 模块3渲染 (直读快照)
              └───────────┘
HAL ──事件──► EventBus ──► Service(DEV:RU) ──窄接口──► DataStore
                               │
Workflow ──窄接口──►│ DataStore │◄──CRUD── Service(各模块)
                    └──────────┘
UI ──► Service(查询) ─ ─► DataStore
UI ──直读──► DataPlane (仅模块3渲染)

★ 每个数据对象有且仅有一个所有者(Data层Store)
★ UI 层全局只读, 无任何写权限
★ Algorithm 层零数据权限, 纯参数进出
```

## 11 个产品模块定义

> 分类轴：**业务类** = 操作员日常扫描工作流的一部分；**平台类** = 监控/运维/支撑性质。

### 业务功能模块（7个）

| # | 模块 | 功能说明 | 主层 | 跨层涉及 |
|---|------|---------|------|---------|
| 1 | 标定 | 25姿态采集 → 解算相机内外参/立体矫正/激光平面映射表(plane_map)/温度补偿表，产出可复用标定参数（离线batch）；**运行时温度补偿查询接口**（`getCompensatedParams(temp)`，模块8喂温度/模块2消费） | Workflow | Algorithm(标定算子) · Data(标定数据) · Service(温度补偿查询) |
| 2 | 扫描（双模式：纯标记点 / 标记点+激光） | 实时扫描180fps。**ScanMode驱动**：纯标记点用mask_extract+单链(激光OFF)；标记点+激光用mask_separation+双链并行(激光ON)。两模式共享ccl+标记点链+配准+融合 | Workflow | Algorithm(core/mask_extract·scanning/mask_separation+激光链) · HAL(激光器开关) · Data(RingBuffer) · Service(ScanConfig) |
| 3 | 渲染显示 | 点云实时3D渲染（CUDA-GL零拷贝），标记点/激光点云viewer | UI | 渲染组件自含(display/) · Data(只读直读ADR7.8) |
| 4 | 后处理 | 离线batch七阶段（全局标记点优化→重融合→**法线计算**→封装→补洞→光顺→边界优化），出STL | Workflow | Algorithm(GBA/法线算子/网格算子) · Data(ArtifactStore) |
| 5 | 编辑（含撤销/重做+操作历史） | 扫描时选中/标记/删除点云或标记点；命令栈支持undo/redo+操作历史可追溯 | Service | UI(编辑界面) · Data(点云裁剪/历史) |
| 6 | 文件管理 | PLY/STL/标定参数导入导出，工程/工件文件组织 | Data | Service(导入导出服务) · UI(界面) |
| 7 | 会话管理 | 扫描启/停/暂停/恢复、覆盖率统计、断电续扫、会话元数据 | Service | Workflow(扫描工作流跑在会话内) · UI(会话控制) · Data(会话元数据) |
