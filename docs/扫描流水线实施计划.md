# 扫描流水线实施计划

## 概述

统一扫描流水线，支持三种模式，共用一条处理链。核心思想：**每帧重建3D标志点 → 与参考点集配准 → 应用变换到激光点**。

## 三种模式

| 模式 | 参考点集来源 | 激光 | 参考点集更新 | 全局优化 |
|------|------------|------|------------|---------|
| 扫描标志点 | 之前帧累积 | 无 | 追加新标志点 | 可选 |
| 标志点+激光 | 之前帧累积 | 有 | 追加新标志点 | 可选 |
| 导入标志点+激光 | 外部导入（固定） | 有 | 不更新 | 不需要（已优化） |

三种模式结构完全相同，只是参考点集来源、是否有激光、是否更新参考点集这三点不同。

## 统一处理流程

```
每帧 processFrame(left, right):

1. 检测+重建3D标志点
   ├── mask_extract        提取标志点mask
   ├── edge_match          边缘匹配
   ├── ellipse_fit         椭圆拟合
   ├── marker_match        左右匹配
   └── point_reconstruct   三角化→3D标志点（相机坐标系）

2. 配准（与参考点集对齐）
   ├── 粗配准
   │   ├── 每个3D标志点找参考点集最近邻
   │   ├── 距离阈值过滤
   │   └── SVD求最优刚性变换 T_init
   └── 精配准 ICP
       ├── 以 T_init 为初始
       ├── 循环（最多50次）
       │   ├── 应用当前T，找最近邻
       │   ├── 过滤离群点
       │   ├── SVD求新T
       │   └── 收敛判断（ΔT < ε）
       └── 输出 T_final

3. 记录帧历史（全局优化用）
   frameHistory.push_back({
     pose: T_final,
     localMarkers: 本帧相机坐标系3D标志点,
     correspondenceIndices: 与参考点集的对应关系
   })

4. 更新参考点集
   if (!referenceFixed)
     把本帧3D标志点（应用T_final后）追加到referenceMarkers

5. 激光处理（laserEnabled时）
   ├── steger_extract      激光中心线提取
   ├── epipolar_interp     极线匹配
   ├── laser_reconstruct   3D激光点（相机坐标系）
   ├── 应用 T_final        → 全局坐标
   └── laserCloud.append()

6. 返回本帧结果
```

## finish() 流程

```
finish():

if (globalOptEnabled)
  ├── 全局优化
  │   ├── 构建因子图（所有帧的标志点观测）
  │   ├── 优化所有帧位姿 + 所有点位置
  │   │   （调 global_ba_cpu 算子 或 LM自行实现）
  │   ├── 用新位姿重新变换所有激光点
  │   └── 输出优化后的 referenceMarkers + laserCloud
  └── 

return {
  markerCloud: referenceMarkers,
  laserCloud: laserCloud,
  normals: laserNormals,
  totalFrames: frameCount
}
```

## 类设计

```cpp
// scan_pipeline.h

enum class ScanMode {
    MarkersOnly,            // 扫描标志点
    MarkersAndLaser,       // 标志点+激光
    ImportedMarkersAndLaser // 导入标志点+激光
};

struct ScanFrameResult {
    bool success = false;
    std::string message;

    // 本帧增量
    std::vector<cv::Point3f> newMarkerPoints;  // 本帧新增标志点（全局坐标）
    std::vector<cv::Point3f> newLaserPoints;   // 本帧新增激光点（全局坐标）

    // 位姿
    cv::Matx44d pose = cv::Matx44d::eye();

    // 累积统计
    int totalFrames = 0;
    size_t totalMarkerPoints = 0;
    size_t totalLaserPoints = 0;
};

struct ScanFinalResult {
    bool success = false;
    std::string message;
    std::vector<cv::Point3f> markerCloud;     // 标志点云（全局）
    std::vector<cv::Point3f> laserCloud;      // 激光点云（全局）
    std::vector<cv::Point3f> laserNormals;    // 法线
    int totalFrames = 0;
};

class ScanPipeline {
public:
    // ===== 配置 =====
    void setCalibration(const CameraCalibResult& calib);
    void setMode(ScanMode mode);
    void setReferenceMarkers(const std::vector<cv::Point3f>& markers);
    void setGlobalOptimizationEnabled(bool enabled);

    // ===== 生命周期 =====
    void start();
    ScanFrameResult processFrame(const cv::Mat& left, const cv::Mat& right);
    ScanFinalResult finish();

    // ===== 状态查询 =====
    int frameCount() const;
    size_t totalPoints() const;

private:
    // --- 配置 ---
    const CameraCalibResult* calib_ = nullptr;
    ScanMode mode_ = ScanMode::MarkersOnly;
    bool laserEnabled_ = false;
    bool referenceFixed_ = false;
    bool globalOptEnabled_ = false;

    // --- 参考点集 ---
    std::vector<cv::Point3f> referenceMarkers_;

    // --- 帧历史 ---
    struct FrameRecord {
        cv::Matx44d pose;
        std::vector<cv::Point3f> localMarkers;
        std::vector<cv::Point3f> localLaser;
        std::vector<int> correspondences;
    };
    std::vector<FrameRecord> frameHistory_;

    // --- 累积输出 ---
    std::vector<cv::Point3f> laserCloud_;
    std::vector<cv::Point3f> laserNormals_;
    int frameCount_ = 0;

    // ===== 内部步骤 =====

    // 1. 检测+重建3D标志点
    std::vector<cv::Point3f> detectAndReconstruct(
        const cv::Mat& left, const cv::Mat& right);

    // 2a. 粗配准
    cv::Matx44d coarseAlign(
        const std::vector<cv::Point3f>& src,
        const std::vector<cv::Point3f>& dst,
        std::vector<int>& matches);

    // 2b. 精配准ICP
    cv::Matx44d refineICP(
        const std::vector<cv::Point3f>& src,
        const std::vector<cv::Point3f>& dst,
        const cv::Matx44d& init);

    // 3. 激光重建
    std::vector<cv::Point3f> reconstructLaser(
        const cv::Mat& left, const cv::Mat& right);

    // 4. 全局优化
    void runGlobalOptimization();

    // 辅助
    static void applyTransform(
        std::vector<cv::Point3f>& points, const cv::Matx44d& T);
    static cv::Matx44d svdRigidTransform(
        const std::vector<cv::Point3f>& src,
        const std::vector<cv::Point3f>& dst,
        const std::vector<int>& matches);
};
```

## setMode 内部逻辑

```cpp
void ScanPipeline::setMode(ScanMode mode) {
    mode_ = mode;
    switch (mode) {
        case ScanMode::MarkersOnly:
            laserEnabled_ = false;
            referenceFixed_ = false;
            globalOptEnabled_ = true;   // 默认开
            break;
        case ScanMode::MarkersAndLaser:
            laserEnabled_ = true;
            referenceFixed_ = false;
            globalOptEnabled_ = true;   // 默认开
            break;
        case ScanMode::ImportedMarkersAndLaser:
            laserEnabled_ = true;
            referenceFixed_ = true;     // 导入点集不更新
            globalOptEnabled_ = false;  // 已优化
            break;
    }
}
```

## 配准算法细节

### 粗配准（标志点对应 + SVD）

```
输入：newMarkers（相机坐标系，N个），referenceMarkers（全局坐标系，M个）

1. 对每个 newMarker[i]:
   - 在 referenceMarkers 中找欧氏最近邻 j
   - 记录距离 d[i]
2. 过滤：丢弃 d[i] > threshold 的对应（阈值如 5mm）
3. 设有效对应 (src[i], dst[j])
4. SVD 求刚性变换：
   - 计算 src 和 dst 的质心
   - 去质心化
   - H = Σ src_centered * dst_centered^T
   - SVD: H = U * Σ * V^T
   - R = V * U^T (检查 det(R)=+1)
   - t = dst_centroid - R * src_centroid
5. 输出 T = [R t; 0 1] + matches
```

### 精配准（ICP）

```
输入：src, dst, T_init

T = T_init
for iter in 0..49:
    1. src_transformed = apply(src, T)
    2. 对每个 src_transformed 找 dst 最近邻
    3. 过滤离群点（距离 > 2*中位数）
    4. T_new = SVD(src, dst_matched)
    5. T = T_new compose T
    6. if ||T_new - T|| < epsilon: break

输出：T
```

### 全局优化

```
输入：frameHistory（所有帧位姿+标志点观测+对应关系）

方法1（简单）：GlobalBACpu 算子
- 构建 BA 问题
- 优化所有帧位姿 + 所有点位置
- 最小化重投影误差

方法2（自行实现）：Pose Graph + LM
- 每帧位姿作为节点
- 标志点观测作为约束
- Levenberg-Marquardt 求解
- 收敛后更新位姿和点位置

优化后：
- 用新位姿重新变换所有帧的激光点
- 更新 laserCloud 和 referenceMarkers
```

## 实施步骤

| 阶段 | 内容 | 依赖 |
|------|------|------|
| **P0** | 接口定义 `scan_pipeline.h` | 无 |
| **P1** | 框架实现：mode切换 + processFrame/finish 骨架 | P0 |
| **P2** | 标志点检测+重建：对接 mask_extract → marker_match → point_reconstruct | P1 |
| **P3** | 配准：粗配准(SVD) + ICP 自行实现 | P1 |
| **P4** | 帧累积：referenceMarkers 更新 + laserCloud 累积 | P2, P3 |
| **P5** | 激光重建：对接 steger_extract → epipolar_interp → laser_reconstruct | P4 |
| **P6** | 全局优化：对接 global_ba_cpu 或自行实现 LM | P4 |
| **P7** | UI 集成：替换 stub，连接扫描按钮 | P4-P6 |

先做 P0-P4（标志点链 + 配准），P5（激光）和 P6（全局优化）后补。

## 四个标志位组合

| 场景 | laserEnabled | referenceFixed | globalOptEnabled | referenceMarkers 初始 |
|------|-------------|---------------|-----------------|---------------------|
| 扫描标志点 | false | false | true | 空（累积） |
| 标志点+激光 | true | false | true | 空（累积） |
| 导入标志点+激光 | true | true | false | 导入的3D点（固定） |
