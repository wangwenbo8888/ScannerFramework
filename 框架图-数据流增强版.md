## 数据流方向总览

```
           写入方向 ──►        查询方向 ─ ─►

HAL ──►F────►│ DataPlane │◄──CRUD── Workflow (热路径直读写)
     ──►DEV──►│           │◄──R───── 模块3渲染 (直读快照)
              └───────────┘
HAL ──事件──► EventBus ──► Service(DEV:RU) ──窄接口──► DataStore
                               │
Workflow ──窄接口──►│ DataStore │◄──CRUD── Service(各模块)
                    └──────────┘
UI ──► Service(查询) ─ ─► DataStore
UI ──直读──► DataPlane (仅模块3渲染)

★ 每个数据对象有且仅有一个所有者(Data层Store)
★ UI 层全局只读, 无任何写权限
★ Algorithm 层零数据权限, 纯参数进出
```
